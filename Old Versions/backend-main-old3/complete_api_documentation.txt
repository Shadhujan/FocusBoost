# FocusBoost API Documentation (until child management)

## Base URL
```
Development: http://localhost:8000
```

## 🔐 Authentication Endpoints

### 1. User Registration
**Endpoint:** `POST /register`

**Request Schema:**
```json
{
  "fullName": "string",
  "email": "user@example.com",
  "password": "string (min 8 characters)",
  "confirmPassword": "string"
}
```

**Success Response (201 Created):**
```json
{
  "id": "firebase-user-id",
  "full_name": "John Doe",
  "email": "john@example.com"
}
```

**Error Responses:**
```json
// 400 Bad Request - Passwords don't match
{
  "detail": "Passwords do not match"
}

// 400 Bad Request - Email already exists
{
  "detail": "Email already registered"
}

// 500 Internal Server Error
{
  "detail": "Error message"
}
```

### 2. User Login
**Endpoint:** `POST /login`

**Request Schema:**
```json
{
  "email": "user@example.com",
  "password": "string",
  "rememberMe": false  // optional
}
```

**Success Response (200 OK):**
```json
{
  "access_token": "firebase-custom-token",
  "token_type": "bearer",
  "user_id": "firebase-user-id",
  "email": "john@example.com",
  "full_name": "John Doe"
}
```

**Error Responses:**
```json
// 401 Unauthorized - Invalid credentials
{
  "detail": "Invalid email or password"
}

// 500 Internal Server Error
{
  "detail": "Error message"
}
```

### 3. Password Reset
**Endpoint:** `POST /forgot-password`

**Request Schema:**
```json
{
  "email": "user@example.com"
}
```

**Success Response (200 OK):**
```json
{
  "message": "Password reset email sent successfully"
}
```

**Error Responses:**

```json
}
```

## 👶 Child Management Endpoints

### 1. Create Child Profile
**Endpoint:** `POST /api/children`

**Request Schema:**
```json
{
  "name": "string",
  "age": "integer (6-12)",
  "parentId": "string (Firebase user ID)",
  "seed": "string (optional - for avatar generation)"
}
```

**Example Request:**
```json
{
  "name": "Emma",
  "age": 8,
  "parentId": "firebase-parent-id",
  "seed": "custom-seed-123"
}
```

**Success Response (201 Created):**
```json
{
  "id": "firestore-document-id",
  "name": "Emma",
  "age": 8,
  "parentId": "firebase-parent-id",
  "avatar": "https://api.dicebear.com/7.x/adventurer/svg?seed=custom-seed-123&backgroundColor=b6e3f4,c0aede,ffd5dc,ffdfbf&backgroundType=solid",
  "seed": "custom-seed-123",
  "createdAt": "2025-01-15T10:30:00.000Z"
}
```

**Error Responses:**
```json
// 500 Internal Server Error
{
  "detail": "Error creating child: [error details]"
}
```

## 📋 Data Models

### User Registration Model
```typescript
interface UserRegister {
  fullName: string;
  email: string;          // Valid email format
  password: string;       // Minimum 8 characters
  confirmPassword: string;
}
```

### User Login Model
```typescript
interface UserLogin {
  email: string;
  password: string;
  rememberMe?: boolean;   // Optional, defaults to false
}
```

### Child Create Model
```typescript
interface ChildCreate {
  name: string;
  age: number;           // Integer between 6-12
  parentId: string;      // Firebase user ID
  seed?: string;         // Optional avatar seed
}
```

### Child Response Model
```typescript
interface ChildResponse {
  id: string;            // Firestore document ID
  name: string;
  age: number;
  parentId: string;
  avatar: string;        // DiceBear avatar URL
  seed: string;          // Avatar generation seed
  createdAt: string;     // ISO 8601 timestamp
}
```

### Child Update Model
```typescript
interface ChildUpdate {
  name?: string;         // Optional
  age?: number;          // Optional
  seed?: string;         // Optional - regenerates avatar
}
```

## 🔒 Authentication

### Bearer Token Authentication
Most endpoints (except registration and login) require authentication:

**Header:**
```
Authorization: Bearer <firebase-custom-token>
```

**Example:**
```bash
curl -H "Authorization: Bearer eyJhbGciOiJSUzI1NiIsInR5cCI6IkpXVCJ9..." \
     http://localhost:8000/api/children/firebase-parent-id
```

## 🧪 Testing Examples

### Create and Manage Child Profile Flow

**1. Register User:**
```bash
curl -X POST http://localhost:8000/register \
  -H "Content-Type: application/json" \
  -d '{
    "fullName": "John Doe",
    "email": "john@example.com",
    "password": "password123",
    "confirmPassword": "password123"
  }'
```

**2. Login:**
```bash
curl -X POST http://localhost:8000/login \
  -H "Content-Type: application/json" \
  -d '{
    "email": "john@example.com",
    "password": "password123"
  }'
```

**3. Create Child:**
```bash
curl -X POST http://localhost:8000/api/children \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer <token>" \
  -d '{
    "name": "Emma",
    "age": 8,
    "parentId": "firebase-user-id"
  }'
```

**4. Get Children:**
```bash
curl http://localhost:8000/api/children/firebase-user-id \
  -H "Authorization: Bearer <token>"
```

## 🚫 Error Handling

### HTTP Status Codes
- `200` - Success
- `201` - Created successfully
- `400` - Bad request (validation error)
- `401` - Unauthorized (authentication failed)
- `404` - Resource not found
- `500` - Internal server error

### Error Response Format
```json
{
  "detail": "Error description"
}
```

## 📊 Database Collections

### Children Collection (Firestore)
```
Collection: children
Document Structure:
{
  name: string,
  age: number,
  parentId: string,
  avatar: string,
  seed: string,
  createdAt: timestamp,
  updatedAt: timestamp
}
```

### Relationships
- **Users → Children**: One-to-Many (parentId reference)
- **Future**: Children → Sessions: One-to-Many
- **Future**: Sessions → AttentionData: One-to-Many
